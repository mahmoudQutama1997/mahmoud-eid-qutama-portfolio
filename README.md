# Mahmoud Eid Qutama — Portfolio

A responsive React + Vite personal portfolio.

## Run locally
1. Install Node.js (LTS).
2. Extract this folder.
3. Open a terminal in the project folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL printed by Vite.

## Before publishing
Open `src/App.jsx` and update:
- `email` with your real public contact email.
- `linkedin` with your LinkedIn profile URL.
- Project links/descriptions to match the public repositories and demos you want to show.

The profile photo is in `public/images/mahmoud.jpg` and is used as supplied.

## Publish on Vercel
1. Push this project to a new GitHub repository.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the repository.
4. Framework: Vite (usually detected automatically).
5. Build command: `npm run build`
6. Output directory: `dist`
7. Click Deploy.

No environment variables are required for this version.
